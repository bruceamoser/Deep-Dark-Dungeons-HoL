# Four Lanterns Deep creature pilots — November 10, 2026

Created in Blender 5.2.4 LTS with `scripts/toolchain/build_creature_pilots.py`.
Editable files: `art/source/creatures/*.blend`. Provenance/hashes/budgets:
`docs/creature-pilots-provenance.json`.

Wererat retains the CC0 KayKit Ninja body's original mesh/weights/rig, with new
rat anatomy, clothing materials and four tail joints. Clay Helper reuses that
23-joint CC0 rig with wholly new clay geometry. Kay Lousberg / KayKit donor terms
are retained in `public/assets/characters/LICENSE.txt`; original donor unchanged.
Both use the game's existing shared KayKit animation library, not embedded clips.

Air Vortex, Goblin Spear and Goblin Pan geometry and all new materials are original
Bruce Moser project contributions. No additional public license is assigned by
this notice. No paid model, cloud-generated mesh, external texture or source-book
illustration is included in these files.

These are first-pass pilots, not claims of finished dark-fantasy production art.
