# Deep Dark Dungeons - HoL

A desktop, single-player, 3D isometric dungeon-delving RPG for a party of four, based on **Heroes of Legend**.

## Confirmed direction

- Original fantasy HoL rules and full character creation.
- Real-time exploration transitioning into turn-based combat.
- Procedural dungeon depth and replayability inspired by Moria.
- Stylized dark fantasy, with a high-end presentation target.
- Free character and environment assets initially; visible gear and outfits.

## Status

Pre-production. No playable build yet. Engine and asset evaluation are underway. This repository does not claim that a prototype implements the complete HoL rules.

See [production brief](docs/production-brief.md) and [rules intake](docs/rules-intake.md).
