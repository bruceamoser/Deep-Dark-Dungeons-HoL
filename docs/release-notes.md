**v0.5.0 — The Build Forge**

- Build distinctive heroes with **30 mastery talents across six branches**, mutually exclusive capstones, free town refunds, and three effect-based specializations for each learned active power. Turn attacks into bursts, deepen conditions, or trade action cost for reach and support.
- Choose from **three signatures per class at each tier** (levels 1, 3 and 7): 90 signature designs, combining active powers with passive build bonuses. The game catalog now contains 225 powers.
- Ordinary powers are **at will**, balanced by actions, positioning and supplies. No encounter/rest charge counters. Repeated fields and action-granting powers are bounded to prevent stacking loops.
- Exploit combat combinations: shatter Freezing with physical hits, conduct lightning through water, build around concealment or flanking, and slam enemies into walls. Burning and other severity conditions accumulate.
- Find eight unique boss relics and more varied procedural enchantments. A persistent run-wide registry prevents repeated newly generated magic-item names or relics. Equipped magic gear glows and carries rune marks; dormant enchantments remain visually distinct.
- Give companions starting gear as well as recovered loot. Drop stacks on the dungeon floor to reduce carried bulk, then recover them through ground-cache interactions. Remaining consumable supplies persist.
- See known disciplines and ranks on the character sheet. Vanish fades the character and shows concealment effects and a sheet badge.
- Reach the first earned level at 400 XP. **Training & builds** in town and the sheet's **Level up** button make advancement accessible. Existing XP and heroes are preserved; faster thresholds may unlock additional earned levels.

### Install

- **Debian/Ubuntu x64:** download `Deep-Dark-Dungeons-HoL-0.5.0-amd64.deb`, then run `sudo apt install ./Deep-Dark-Dungeons-HoL-0.5.0-amd64.deb`. The package configures its own sandbox helper.
- **Other Linux x64:** download the AppImage or `linux-x64.tar.gz` installer bundle. Extract the bundle and run `bash install-linux.sh`. Restricted Ubuntu AppImage users need Chrome/Chromium's trusted sandbox helper.
- **Windows x64:** run `Deep-Dark-Dungeons-HoL-Setup-0.5.0-x64.exe`. The installer is unsigned.

Installed games check and download updates. **Updates → Save & restart to install** saves the current journey first; Debian upgrades may request administrator authorization. The source-checkout launcher runs its rebuilt local copy instead of self-updating.

This is a substantial gameplay iteration, with campaign balance and production art still in development. Existing duplicated items are retained; the new registry governs future generation. Original book/Foundry files and vendored rules remain unchanged. See `docs/v0.5-gameplay-design.md` for adaptations and research.
