**v0.6.0 — The Discipline Forge**

Character progression has been rebuilt around a connected atlas: **18 discipline origins, 72 circular paths, 377 purchasable or granted circles, and 33 combined techniques**.

- Class, culture and background each grant a discipline origin. Follow its paths, or purchase another discipline from level 2. Flame and Frost occupy opposite sides; Armor and Guard are neighbors.
- Spend one persistent currency: **8 starting DP and 4 per trained level**, up to level 30. Duplicate origin grants return 3 DP. The old ability shop, mastery currency and fixed class signatures have left the player flow.
- Small circles improve damage profiles, range, movement, protection, conditions, healing, crafting and other effects. Larger techniques change what your hero can do. Marksmanship develops from **1/1/2 → 1/2/2 → 1/2/3 → 2/3/5**, with a separate range path and **Twin Shot**.
- Confluences combine two, three or four disciplines. Every prerequisite circle touching the border must be learned; the border then opens so you can purchase the central skill. Search, inspect prerequisites, pan and zoom to plan a build.
- Train earned levels in the forge. Preview refunds before removing a path and its dependent purchases. Full respec remains free in Greyhaven and preserves XP, equipment, remaining supplies and injuries without healing or restoring spent Grit.
- A seven-step creator starts blank, previews origin grants and appearance, opens the same forge, and offers equipment kits plus a 60-coin purse. Extra equipment can be added and removed directly.
- Weapon powers and reactions use learned attack profiles. Twin Shot rolls and checks ammunition separately, with visibly staggered arrows. Combined barriers and buffs remain active together. Powers remain at will, with action, equipment, positioning and supply requirements.

**Start a new journey.** v0.6 deliberately replaces the previous progression system. Older save files remain on disk and appear as **Earlier edition · preserved** in Saved journeys; they cannot be played by this edition. Install v0.5.1 separately if you want to revisit them. Your new v0.6 runs remain independent and support normal saving and respec.

### Install

- **Debian/Ubuntu x64:** download `Deep-Dark-Dungeons-HoL-0.6.0-amd64.deb`, then run `sudo apt install ./Deep-Dark-Dungeons-HoL-0.6.0-amd64.deb`.
- **Other Linux x64:** download the AppImage or `linux-x64.tar.gz` installer bundle. Extract the bundle and run `bash install-linux.sh`.
- **Windows x64:** run `Deep-Dark-Dungeons-HoL-Setup-0.6.0-x64.exe`.

Installed releases check for updates and download them. **Updates → Save & restart to install** saves before upgrading; Debian upgrades may request administrator authorization. The source-checkout launcher uses its rebuilt local copy.

This is a substantial playable progression iteration. Long-term balance and final production art/audio remain in development. The source book, Foundry repository and vendored HoL rules are unchanged.
