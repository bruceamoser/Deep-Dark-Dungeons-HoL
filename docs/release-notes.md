**v0.4.0 — Powers, identity and clearer battlefields**

- Game-designed powers over HoL mechanics: 54 discipline powers, 30 class signatures and three consumable actions, with explicit costs, targets and limits. Existing characters retain their history and receive mapped playable powers.
- Shared effects for attacks, healing, protection, conditions, movement, concealment, light and limited action resources. Ground targeting previews areas before spending.
- Fire, dousing water, smoke, difficult ground, barriers, light/darkness, healing circles and one-use traps. Persistent hazards affect both sides.
- Eleven learned recipes: buy or discover knowledge, purchase ingredient batches, craft items or replenish supplies. Predictable camp/infirmary wound treatment preserves scars and spent Grit.
- Individual hero appearance: sex, ancestry features and proportions, face/build, skin, hair, facial hair, eye color and clothing theme. Preview live, save with the hero, and see it on their equipped dungeon model.
- Clear tactical squares, reachable movement shading and hover costs. Teal marks reachable destinations; gold marks the last movement point. G toggles the exploration grid.
- Delete active or old runs with a named confirmation. Other runs remain intact; deleted legacy runs stay deleted after restart.

### Install

- **Debian/Ubuntu x64:** download `Deep-Dark-Dungeons-HoL-0.4.0-amd64.deb`, then run `sudo apt install ./Deep-Dark-Dungeons-HoL-0.4.0-amd64.deb`. The package configures its own sandbox helper.
- **Other Linux x64:** download the AppImage or `linux-x64.tar.gz` installer bundle. Extract the bundle and run `bash install-linux.sh`. Restricted Ubuntu AppImage users need Chrome/Chromium's trusted sandbox helper.
- **Windows x64:** run `Deep-Dark-Dungeons-HoL-Setup-0.4.0-x64.exe`. The installer is unsigned.

Installed games check and download updates. **Updates → Save & restart to install** saves the current journey first; Debian upgrades may request administrator authorization. The source-checkout launcher runs its rebuilt local copy instead of self-updating.

This remains a playable development release. The appearance system uses modular geometry on licensed rigs; bespoke production art, additional recipes and long-term balance remain in development. Original book/Foundry files and vendored rules are unchanged.
