**v0.5.1 — A new path for the same hero**

- In Greyhaven, open a character sheet and choose **Respec from beginning**. Rebuild attributes, ancestry, traits, origins, class, disciplines, abilities and all three signature tiers using the current game catalog.
- Rebuild every previously trained level. Keep the same hero, earned XP and untrained levels, appearance, equipment, remaining supplies, learned recipes, injuries and expedition history. Mastery and specializations return to unspent points.
- Your existing character stays intact until **Confirm respec**. Close the creator to cancel; a separate local rebuild draft can be resumed later. Recruitment drafts remain separate.
- Respec is free in town. It grants no extra starting purse or equipment, does not heal injuries, and cannot restore spent Grit by switching builds. Armor that the new build cannot wear goes into the backpack.
- Fixed two-handed ordinary weapons losing their selected grip after transfer/reload, and empty water flasks losing their supply state when moved between inventories. Valid d20 supply stacks now save correctly.

### Install

- **Debian/Ubuntu x64:** download `Deep-Dark-Dungeons-HoL-0.5.1-amd64.deb`, then run `sudo apt install ./Deep-Dark-Dungeons-HoL-0.5.1-amd64.deb`. The package configures its own sandbox helper.
- **Other Linux x64:** download the AppImage or `linux-x64.tar.gz` installer bundle. Extract the bundle and run `bash install-linux.sh`. Restricted Ubuntu AppImage users need Chrome/Chromium's trusted sandbox helper.
- **Windows x64:** run `Deep-Dark-Dungeons-HoL-Setup-0.5.1-x64.exe`. The installer is unsigned.

Installed games check and download updates. **Updates → Save & restart to install** saves the current journey first; Debian upgrades may request administrator authorization. The source-checkout launcher runs its rebuilt local copy instead of self-updating.

Existing characters remain playable without respec. Use it when you want to discard the historical build and select current powers from scratch. Production art and campaign balance remain in development. Original book/Foundry files and vendored rules remain unchanged.
