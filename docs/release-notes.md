**v0.8.1 — Ready for the Depths**

A patch for Dungeon Mason character presentation and inventory handling.

- **Upright torches.** Corrected the held torch direction for both hands, including lit and unlit models.
- **Appearance changes anywhere.** Customize your hero and ordinary melee/ranged weapon styles in Greyhaven, dungeon exploration or combat. Cosmetic changes spend no actions, time or character resources.
- **Magic weapons keep their identity.** Enchanted swords remain swords and longbows remain bows, with a consistent item-specific model variant across cosmetic edits, equipment changes and saved journeys. Ordinary weapon styles remain freely customizable.
- **Combine matching supplies.** In the inventory, select ammunition or another consumable and choose **Combine with matching bundle → Combine supplies**. Combining is available outside combat. One entry preserves each remaining supply die and uses them in sequence; no supply is refilled or discarded, and bulk stays unchanged. Combined supplies survive saves, transfers, drops and recovery.

**Existing v0.6–v0.8 journeys continue.** Saves, inventory, progression and injuries are preserved. Dungeon Mason class outfits and customizable headwear remain cosmetic; equipped armour controls protection. Unusual cosmetic combinations may overlap.

### Install or update

- **Debian/Ubuntu x64:** install `Deep-Dark-Dungeons-HoL-0.8.1-amd64.deb` with `sudo apt install ./Deep-Dark-Dungeons-HoL-0.8.1-amd64.deb`.
- **Other Linux x64:** download the AppImage or Linux bundle. Extract the bundle and run `bash install-linux.sh`. Restricted Ubuntu AppImage installations require a system Chrome/Chromium sandbox helper.
- **Windows x64:** run `Deep-Dark-Dungeons-HoL-Setup-0.8.1-x64.exe` (unsigned).

Installed releases can use **Updates → Save & restart to install**. Debian upgrades may request administrator authorization.

The finished releases include licensed Dungeon Mason character art and KayKit scenery. Public source-only builds use KayKit fallback characters unless purchased exports are staged. Purchased source and standalone model exports are not distributed. The source book, Foundry repository and vendored HoL rules are unchanged.
