# Area arrow techniques

Marksmanship’s existing Barbed Arrow node becomes **Barbed Volley** (same saved power/node IDs). It targets a radius1 ground area within8 squares, deals its existing physical damage and Bleeding1 to enemies, and is available on the existing early Penetration branch. Serrated Arrow still upgrades its Bleeding. Piercing Flight retains its long-line attack.

Flaming Arrow and Thorn Arrow confluences target radius1 within6 squares, retaining their bow profile and Burning2 or Slowed2/Bleeding1 respectively. Instant hostile areas spare allies, use normal line of sight and do not pass through walls. No persistent fire surface is created by these arrows.

All three require learned technique, readied bow and usable ammunition. One Main Action and one ammunition supply check pay for the volley; a last exhausted use still resolves against the whole area. Pointer targeting previews recipients; cancellation is free. Existing action, counter and save rules apply. These are explicit game-owned ability adaptations, not changes to printed source cards or equipment bonuses.
